## AutoClicker v1.0.0

Primeira versão.

- Alvo circular arrastável e painel flutuante (▶/⏸, ✕)
- Intervalo entre cliques configurável (mínimo 20 ms)
- Toques via serviço de acessibilidade

**Instalação:** baixe o APK abaixo. Se o Android bloquear, veja a seção "Como compilar e instalar" do README (Play Protect e configurações restritas).

> As builds a partir desta versão usam assinatura fixa, então atualizações instalam por cima. Se você tinha instalado uma build anterior, desinstale-a uma única vez antes.
